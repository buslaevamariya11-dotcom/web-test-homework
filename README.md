# Web-test-homework

![CI Status](https://github.com/buslaevamariya11-dotcom/web-test-homework/actions/workflows/gradle.yml/badge.svg)

Описание вашего проекта. Этот проект создан для выполнения домашнего задания по тестированию веб-приложений.

## Как запустить

1. Склонируйте репозиторий:
   `git clone https://github.com/buslaevamariya11-dotcom/web-test-homework.git`
2. Соберите проект:
   `./gradlew build`
3. Запустите тесты:
   `./gradlew test`

## Отчет о тестировании

1. Орфографические ошибки в интерфейсе
    * **Тест:** shouldShowErrorWhenNameIsInvalid
    * **Статус:** FAIL
    * **Описание:** В сообщении об ошибке поля "Фамилия и имя" используется некорректная форма причастия: «указаные»
      вместо «указаны».
    * **Подробности:** См. Issue #3

2. Несоответствие текста ошибки ТЗ (Поле Телефон)
    * **Тест:** shouldShowErrorWhenPhoneIsInvalid
    * **Статус:** FAIL
    * **Описание:** Текст ошибки при неверном формате номера не совпадает с требованиями документации (отсутствует
      точка, изменен пример номера).
    * **Подробности:** См. Issue #2
